📖 How to Use Excel Finder

Follow these steps to search your Excel datasets efficiently.

Step 1: File Upload

Upload any .xlsx or .xls file. The app automatically scans sheets, detects tables, and ignores empty columns.

Step 2: Multi-Column Search

Add fields to search across multiple columns simultaneously (e.g., First Name + Father Name + Surname).

Step 3: Matching Logic Options

  • AND Mode: Returns records satisfying all conditions.
  • OR Mode: Returns records satisfying any single condition.

Step 4: Arabic Normalization

Arabic character variations are automatically normalized during searches for accurate results.
